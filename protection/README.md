# Защита дашборда BM

Выбран бесплатный Firebase Spark. Код, ограничения, проверки и порядок включения описаны в [spark/README.md](spark/README.md).

Пакет не переключает рабочий сайт автоматически. Перед закрытием старой базы необходимо проверить личный вход владельца, сохранить свежие частные копии, перенести текущие данные в согласованную паузу и проверить новые правила. Серверные Cloud Functions и платное хранилище не используются.
